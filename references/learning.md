# 學習設計、複習與能力評量

## 主題設定

以「能在某情境獨立完成某任務」定義目標。每個 subject profile 包含先備知識、4–6 個指標、每項量尺錨點、課程單元、可接受的成果形式、教材來源與版本。一次只推進 1–2 個核心概念，先示範、引導，再獨立運用。

| 範例主題 | 能力指標候選 | 獨立輸出 | Vocabulary 內容 |
|---|---|---|---|
| 職場英語 | 文法、詞彙、閱讀、寫作、溝通、自然度 | 模擬回覆與技術說明 | 詞彙、片語、搭配詞 |
| Kubernetes | 架構理解、配置、除錯、安全、可觀測性 | 解釋故障並修正範例配置 | Pod、Service、Probe 與差異 |
| 演算法 | 建模、正確性、複雜度、實作、解釋 | 解題並解釋不變量 | 符號、術語、推理模式 |
| 日文 | 聽解、讀解、文法、詞彙、互動 | 情境對話 | 字詞、讀音、助詞用法 |
| 會計 | 分類、分錄、報表、分析、解釋 | 完成分錄並說明報表影響 | 術語、公式、會計概念 |

以上只是候選，不是所有人的固定六項。主題資料不足先做小型診斷；時效性高的標準、考試範圍或軟體行為需查可靠來源並記錄日期，無來源則標示待確認。

## 均衡課程

預設 55 分鐘（教材 7、複習 8、正課 40），通常允許 50–60 分鐘；以預估時間和認知負荷衡量，不只看字數。每 Day 通常 2–3 題教材、3–5 個複習項目、1 個應用任務、1 個獨立輸出。沒有到期項目時用短先備知識回想，不憑空建卡。

可配置五日循環：概念建立 → 基礎操作 → 問題處理 → 閱讀／分析 → 整合運用。使用課程 Day 進度推動單元，不因星期切換跳過先備內容。連續吃力時縮小範圍、增加引導；熟練時提高遷移難度，維持時間预算。週報是教練行政工作。

## Flashcards 與間隔複習

一張卡聚焦一個可評量目標。Front 是問題／情境，Back 是精簡答案、說明與一個例子；含 concept_id、來源、難度、到期日期與歷次回想結果。為重要概念、反覆錯誤或使用者要求建卡，預設每 Day 最多新增 3 張。

這是可替換的簡單排程政策，不宣称為通用最佳演算法。預設成功後的間隔依序為 **1、3、7、14、30 個日曆日**，從實際複習時間算；到期日落在休息日，移到下一允許的學習日。原始到期日與可執行日期都保留，避免漂移無法追查。

| 回想結果 | 記錄及下次安排 |
|---|---|
| 錯誤／不記得 | streak=0、stage=0；下個允許學習日；當堂可再練但不升級 |
| 正確但需提示／已看答案 | 不增加 streak 或 stage；下個允許學習日再測 |
| 獨立正確 | 在不同日期且到期的測驗才增加 streak；用目前 stage 對應間隔排程，再將 stage +1，上限 4 |
| 未作答／未到場 | 不當成答錯；保留到期狀態，按容量排入後續課程 |

初次建卡 stage=0、streak=0，下個允許學習日測驗。額外提前回想可記錄為 practice，但不推進間隔、streak 或 next_due。第一個到期成功排 1 天、第二個排 3 天，以此類推；階段上限後每次成功排 30 天。

錯題狀態：New（剛記錄）→ Learning（已講解／正在練習）→ Review（至少一次到期獨立正確）→ Mastered（至少三次不同日期的到期獨立正確，且其中至少一次是新情境）。Mastered 再犯錯時回 Review、streak=0、stage=0，下一學習日重測。Mastered 仍保留抽查排程。

同一 concept 的卡片與錯題共享 review item，避免一次作答算成兩次成功。多次出錯保留 event 歷史，不生成一堆重複卡。優先順序：已到期的反覆錯誤／弱項 → 其他到期項目 → 少量新項目；受 5–10 分鐘限制，未抽到的維持到期，不批量標完成。

## Mistake / Error Log

每筆記錄：原始題目與作答、正確／較佳作法、概念、錯誤分類、原因、可執行改進、下一個遷移題、狀態、連續成功數、下次複習與證據引用。分類依主題設定，例如誤解概念、程序順序、計算、表達、工具操作。保留原文，別把修正後答案當成初次表現。

## 能力追蹤與圖表

預設每項 0–4 的觀察量尺：0 尚無法開始；1 需逐步引導；2 可完成熟悉任務但仍需提示；3 可獨立完成熟悉任務並解釋；4 可獨立遷移到新情境並檢查結果。每個主題為這些錨點補上具體任務。無測驗證據為 null，不是 0。自評另欄保存。

每次觀察記錄 metric_id、日期、Day、score、題目難度、是否獨立、rubric_version、evidence_id。圖表優先用各指標分面折線圖，固定 y 軸 0–4；x 軸為當地日期。同日多個 Day 顯示為多筆點位或依明示方法聚合，保留樣本數。少於兩個時間點只呈現基線，不宣稱趋势。

週報可比較同量尺、近似難度的首末獨立表現，列樣本數與限制。量尺改版要標記斷點或分圖，不能把不同指標硬接一條線。不要將教學評分自動換算 TOEIC、CEFR、證照通過率。工具不能繪圖時提供資料表與明確標示的文字趨勢，不能說圖已上傳。
