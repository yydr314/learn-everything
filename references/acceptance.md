# 行為驗收情境

修改規則後，以以下輸入做桌面演練；不真的寄信、刪資料或建立排程。檢查決策與狀態，不能只比對段落文字。若做實際 integration test，使用者授權的測試資源需另行指定。

| 情境／初始狀態 | 必須觀察到的結果 |
|---|---|
| 初次只說「使用 $learn-everything 帶我學英文」，未提 setup 或外部流程 | 第一輪回覆就同時詢問學習需求與可複選流程，明列每日 Email、複習／上課提醒、週報寄送等選項；不等待 setup 關鍵字或診斷結束 |
| 初次已提供目標、程度與每天可用時間，但未提 hooks | 不重問已知學習資料，仍主動詢問流程偏好，不能直接略過入門詢問 |
| 選「稍後決定」或未回答流程問題 | 偏好維持待確認，不啟用服務、不反覆催問；仍可進行對話學習 |
| 只選每日教材 Email | 僅補齊每日寄信的設定與依賴；不連帶啟用週報寄送、複習或上課通知 |
| 選擇只在對話學習 | 保存明確選擇；不強迫串接、不再追問已拒絕流程，可完成 setup 並開始課程 |
| 要每日自動寄 Email，但郵件未連接 | 記錄 mail + automations 依賴、收件人與時區／時段；提醒連接郵件服務及開啟寄送權限，流程 pending，提供對話教材 |
| 郵件可讀但未能確認寄送權限；排程工具可用 | 不把讀取成功當可寄送、不用測試信探測；提示所缺權限，不建立依賴未備妥的自動寄信流程 |
| 宿主沒有選定服務的 connector | 標 unsupported，說明工具限制及可用替代，不編造設定入口或聲稱使用者拒絕授權 |
| 重新連線後續做 setup，既有授權與 job_id 可驗證 | 重驗必要能力、補缺項、查已存在工作；不重問已授權範圍、不重建 job |
| profile 為舊版，或 connected 的服務被撤銷權限 | 舊版缺欄位視為未確認；撤銷權限時暫停受影響流程、提醒補授權，其他課程仍可進行 |
| 新手說「用這套系統學 Kubernetes，每天 20 分鐘」，沒有外部服務 | 收集目標／先備，縮放預算，建立主題指標；對話可以開始，沒有假寄信或假 Drive 連結 |
| 既有 Day 4 在核心概念階段中斷，說「繼續」 | 接續 Day 4 checkpoint，不開始 Day 5 |
| Day 4 已完成，說「還想繼續」 | 直接啟動完整 Day 5；Day 4 不增量 |
| 同日完成 Day 4、5，下個工作日 automation 執行兩次 | 只解析 Day 6；同一教材成功寄送至多一次，兩次執行不增兩次 streak |
| 公定假日、卡片到期、例行教材與週報待產生 | 無主動教材／提醒／課程；卡片保留，週報用該週最後學習日規則；不懲罰補課 |
| 週末使用者主動說「我要上課」 | 本次可上課，不解除整套假日守門、不自動啟用寄信 |
| 假日來源暫時失效且快取不涵蓋今天 | 標 unknown、停止主動派送；可手動教學，不當作確定工作日 |
| 星期五教材答案發布 72 小時後到期；星期一為已確認休假 | 下一允許學習日清理，仍需政策已授權；不能清掉每日複習或錯題證據 |
| 到期清單混有 pinned 答案、外部檔案與普通暫存答案 | 只處理系統登記、正確根目錄、未 pin 且到期的暫存答案；無授權不處理 |
| 到期卡看答案後答對，同一天又獨立答對 | 紀錄練習，但不讓提示後重答／同日重答累積三次 mastery |
| Mastered 再犯錯 | 回 Review、streak=0、stage=0、下一學習日重測，歷史保留 |
| 只有一筆基線、其他指標未測 | 未測 null；沒有虛构成長線、考試分數或達標宣稱 |
| Day 已學完，Drive 失敗 | 明確結課並說明待同步；保留可匯出的結果，下次只補同步 |
| Gmail 回傳 timeout，實際可能已寄送 | 用工作鍵查結果，不盲目重寄；查不明維持 unknown |
| 切換到另一學習者／主題 | 新命名空間，不帶入前一人的弱點、地址、分數與外部資源 ID |

封裝檢查：SKILL.md frontmatter 正確、所有相對連結存在、JSON 可解析、UTF-8 無替代字元、不包含真實學生資料或憑證。此清單不等於已通過外部服務測試。
